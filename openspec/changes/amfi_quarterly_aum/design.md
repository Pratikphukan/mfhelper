# Design: AMFI Quarterly Scheme AUM

## Data Flow

1. Find the newest scheme-wise AAUM quarter published by AMFI.
2. Read the individual scheme and plan/option rows from that report.
3. Match rows to the fund analytics records and calculate the approved AUM
   value in crore rupees.
4. Write `AUM (Cr.)`, `AUM Quarter`, and the existing `Last Updated (IST)` to
   the analytics sheet.
5. If AMFI has not published a newer quarter, use the newest report available
   and show its actual quarter. Do not imply that the AUM is daily or current
   as of the sheet-write timestamp.

## Sheet Columns

Append `AUM Quarter` adjacent to `AUM (Cr.)`. `Last Updated (IST)` continues to
mean the MFHelper run/write time and must not be repurposed as the AUM period.

## Approved Design Decisions

- **Scope:** Applies to all sheets generated by `analytics_main.py` (`Fund Analytics`, category tabs, etc.).
- **AUM Meaning:** Direct Growth plan AAUM only (exact plan code configured in the fund list).
- **Quarter Label Format:** Calendar format (e.g. `Jul-Sep 2026`).

## Data and Failure Handling

- Preserve the report's quarter with every output value.
- If a report cannot be fetched or a scheme cannot be matched, do not present a
  guessed value as current; leave AUM unavailable or use the most recent
  verified value with its original quarter.
- AMFI publishes quarterly average AUM; this design does not provide daily AUM.
